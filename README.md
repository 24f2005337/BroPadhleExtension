# Bro, Padh Le! 😤 - Distraction Killer Chrome Extension

A funny, passive-aggressive Chrome Extension (Manifest V3) designed to save students from infinite doom-scrolling on Instagram, YouTube Shorts, and X (Twitter).

---

## ✨ Features

* 🚨 **Passive-Aggressive Overlays:** Shows dramatic Desi memes and dialogues on distracting sites.
* ⏱️ **Floating Countdown Timer:** Real-time floating ticker reminding you of wasted time when you extend limits.
* 🔥 **Shame Counter:** Tracks how many times you ignored the study warning.
* ⚡ **Screen Glitch Effect:** Screen glitches and shakes during the final 10 seconds of the timer.
* 🕺 **The Rickroll Trap:** Auto-plays a Rickroll video if warnings are ignored repeatedly!

---

## 🛠️ Tech Stack

* **JavaScript (ES6+)**
* **Chrome Extension API (Manifest V3)**
* **CSS3 (Custom Animations & Glitch FX)**

---

## 🚀 How to Install Locally

1. Clone or Download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer Mode** (top-right toggle).
4. Click **Load unpacked** and select the folder.
